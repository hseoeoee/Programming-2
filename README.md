# 프로그래밍2 — C 언어 과제

강릉원주대학교 1학년 C 프로그래밍(프로그래밍2) 수업 과제 코드를 정리한 저장소입니다.
Visual Studio 2022(x64) 솔루션·프로젝트 파일이 함께 있어 바로 열어 빌드할 수 있습니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `HW03/HW03.sln` | HW03 과제 솔루션 |
| `HW03/HW03/HW03.c` | HW03 과제 — 콘솔 화면에 폭탄 `(  b  )`과 심지(`#`)를 그리고, 불꽃(`*`)이 심지를 나선으로 따라가다 폭탄에 닿는 순간 `!!BAM!!`으로 터지는 애니메이션 (200ms 간격, ANSI escape로 커서 이동) |
| `HW03/HW03/HW03.vcxproj` | HW03 프로젝트 파일 |

## 빌드 및 실행

1. `HW03/HW03.sln`을 Visual Studio 2022에서 엽니다.
2. 구성을 `x64 Debug`로 선택하고 빌드(`Ctrl+Shift+B`)한 뒤 실행(`Ctrl+F5`)합니다.
3. `HW03.c`는 `windows.h`의 `Sleep()`과 ANSI escape 코드를 사용하므로 Windows 콘솔에서 실행해야 하며, Windows 10 이상에서 색과 커서 이동이 정상적으로 보입니다.

명령줄에서 바로 빌드하려면:

```
cl HW03/HW03/HW03.c
```

## 참고

- 소스의 한글 주석은 CP949(EUC-KR)로 저장되어 있습니다. Visual Studio에서는 그대로 보이고, 다른 편집기에서는 인코딩을 CP949로 지정해야 깨지지 않습니다.
- 빌드 산출물(`.exe`, `.pdb`, `.ilk`, `.obj`, `x64/`, `Debug/`, `enc_temp_folder/` 등)과 편집기 임시 파일은 `.gitignore`에서 제외합니다.
